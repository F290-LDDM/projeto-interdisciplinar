# Publicar a atividade no GitHub

## Criar o repositório a partir do ZIP

1. Descompacte `atividade-lddm-5-semestre.zip`.
2. Acesse o GitHub com a conta que administra a organização ou conta da disciplina.
3. Crie um repositório novo, por exemplo `atividade-lddm-5-semestre` (ou o nome definido pelo docente). Escolha público ou privado conforme a política da disciplina.
4. Selecione repositório vazio. Não gere README, licença ou `.gitignore` automaticamente, pois os arquivos já estão no pacote.
5. Envie o conteúdo da pasta `atividade-lddm-5-semestre` para a raiz do repositório. A raiz deve conter `README.md`, `TEAMS.md`, `INSTRUCOES-PUBLICACAO.md` e `docs/`.
6. Faça o primeiro commit e confira a página inicial. O GitHub exibirá o `README.md` automaticamente.
7. Copie o link público ou o link com acesso adequado e compartilhe com os estudantes no Teams.

## Texto para o campo “About” do GitHub

Enunciado e materiais de entrega do projeto prático de Laboratório de Desenvolvimento para Dispositivos Móveis (5º semestre): aplicativo Flutter integrado a API própria ou Supabase.

## Publicar o resumo no Teams

Copie o conteúdo de `TEAMS.md` para a tarefa ou publicação no Microsoft Teams. Depois de criar o repositório, substitua os links relativos do resumo pelos links absolutos correspondentes no GitHub, se a publicação do Teams não renderizar links relativos.

## Revisão antes da publicação

- Confirme nome do repositório, turma, docente e eventuais datas locais.
- Confira se os pesos da rubrica foram ratificados pelo docente; ajuste-os antes de publicar, se necessário.
- Confirme que o prazo de apresentação e as orientações de perguntas estão alinhados com o calendário da disciplina.
- Abra os arquivos no GitHub e teste os links internos.
- Distribua aos alunos o link do repositório e a data/orientações oficiais.
